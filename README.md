# Samokat - Selenium Test Automation Project

Автоматизированное тестирование веб-сайта аренды самокатов с использованием Selenium WebDriver и JUnit 5.

## 🚀 Описание проекта

Этот проект содержит автоматизированные тесты для веб-сайта аренды самокатов (https://qa-scooter.praktikum-services.ru/). Тесты покрывают основные пользовательские сценарии:

- Оформление заказа самоката
- Проверка FAQ разделов
- Тестирование логотипов и навигации
- Проверка статуса заказа
- Анализ форм и элементов интерфейса

## 🛠 Технологии

- **Java 11**
- **Selenium WebDriver 4.20.0**
- **JUnit 5**
- **Maven**
- **WebDriverManager 5.7.0**

## 📁 Структура проекта

```
src/test/java/
├── pageobject/
│   ├── MainPage.java      # Page Object для главной страницы
│   └── OrderPage.java     # Page Object для страницы заказа
└── tests/
    ├── FaqTest.java                    # Тесты FAQ разделов
    ├── LogoTest.java                   # Тесты логотипов
    ├── OrderFormAnalysisTest.java      # Анализ форм заказа
    ├── OrderStatusTest.java            # Тесты статуса заказа
    ├── OrderTest.java                  # Основные тесты заказа
    └── PageAnalysisTest.java           # Анализ страниц
```

## 🚀 Запуск тестов

### Запуск в Chrome (по умолчанию)
```bash
mvn test
```

### Запуск в Firefox
```bash
mvn test -Dbrowser=firefox
```

### Запуск конкретного теста
```bash
mvn test -Dtest=OrderTest#testCompleteOrderFlowWithStatusCheck
```

## 📋 Тестовые сценарии

### 1. Оформление заказа (`OrderTest.java`)
- ✅ Оформление заказа через верхнюю кнопку
- ✅ Оформление заказа через нижнюю кнопку
- ✅ Полный цикл с переходом на страницу статуса
- ✅ Случайный выбор станции метро
- ✅ Заполнение всех полей формы

### 2. FAQ тесты (`FaqTest.java`)
- ✅ Проверка открытия/закрытия FAQ разделов
- ✅ Валидация содержимого ответов

### 3. Логотипы (`LogoTest.java`)
- ✅ Клик по логотипу Самоката (остаемся на странице)
- ✅ Клик по логотипу Яндекса (открывается новая вкладка)

### 4. Статус заказа (`OrderStatusTest.java`)
- ✅ Проверка с несуществующим номером заказа
- ✅ Проверка с существующим номером заказа

### 5. Анализ форм (`OrderFormAnalysisTest.java`)
- ✅ Детальный анализ элементов формы заказа
- ✅ Проверка интерактивности элементов

## 🔧 Особенности реализации

### Page Object Pattern
Проект использует паттерн Page Object для лучшей организации кода и переиспользования.

### Поддержка нескольких браузеров
- Chrome (по умолчанию)
- Firefox (через параметр `-Dbrowser=firefox`)

### Надежные селекторы
- Использование JavaScript кликов для избежания проблем с перекрытием элементов
- Retry логика для нестабильных элементов
- Подробное логирование для диагностики

### Обработка модальных окон
- Автоматическое закрытие календаря
- Обработка модальных окон подтверждения
- Проверка успешного оформления заказа
