# Автотесты для сервиса "Яндекс.Самокат"

Этот проект содержит автоматизированные тесты для учебного сервиса "Яндекс.Самокат", разработанного специально для студентов.

## Структура проекта

```
src/test/java/
├── pageobject/
│   ├── MainPage.java      # Page Object для главной страницы
│   └── OrderPage.java     # Page Object для страницы заказа
└── tests/
    ├── FaqTest.java       # Тесты для FAQ (обязательная часть)
    ├── OrderTest.java     # Тесты для заказа самоката (обязательная часть)
    ├── LogoTest.java      # Тесты для логотипов (факультативная часть)
    ├── ValidationTest.java # Тесты валидации полей (факультативная часть)
    └── OrderStatusTest.java # Тесты статуса заказа (факультативная часть)
```

## Технологии

- **Java 11**
- **Maven**
- **JUnit 5**
- **Selenium WebDriver**
- **WebDriverManager**

## Обязательные тесты

### 1. Тесты FAQ (FaqTest.java)
- Проверка выпадающего списка в разделе "Вопросы о важном"
- Параметризованный тест для всех 8 вопросов
- Проверка открытия/закрытия ответов при клике на стрелочку

### 2. Тесты заказа самоката (OrderTest.java)
- Полный флоу позитивного сценария заказа
- Два набора тестовых данных
- Две точки входа: верхняя и нижняя кнопки "Заказать"
- Проверка появления модального окна об успешном заказе

## Факультативные тесты

### 3. Тесты логотипов (LogoTest.java)
- Проверка клика по логотипу "Самокат" (остается на главной странице)
- Проверка клика по логотипу "Яндекс" (открывается в новом окне)

### 4. Тесты валидации (ValidationTest.java)
- Проверка ошибок для всех полей формы заказа
- Тестирование пустых полей
- Тестирование некорректных значений

### 5. Тесты статуса заказа (OrderStatusTest.java)
- Проверка поиска несуществующего заказа
- Проверка сообщения "Заказ не найден"

## Запуск тестов

### Предварительные требования
1. Установить Java 11
2. Установить Maven
3. Установить Google Chrome

### Команды для запуска

```bash
# Сборка проекта
mvn clean compile

# Запуск всех тестов
mvn test

# Запуск только обязательных тестов
mvn test -Dtest=FaqTest,OrderTest

# Запуск конкретного теста
mvn test -Dtest=FaqTest#testFaqDropdownOpens

# Запуск с подробным выводом
mvn test -Dtest=FaqTest -Dsurefire.useFile=false
```

## Особенности реализации

### Page Object Pattern
- Использован паттерн Page Object для лучшей организации кода
- Разделение логики страниц и тестов
- Переиспользование методов

### Параметризация
- Использована параметризация JUnit 5 для тестирования с разными данными
- @CsvSource для тестов с множественными параметрами
- @ValueSource для тестов с одним параметром

### Ожидания
- Использованы явные ожидания (WebDriverWait) для стабильности тестов
- Timeout 10 секунд для всех ожиданий

### Обработка ошибок
- Корректное закрытие браузера в @AfterEach
- Обработка исключений при проверке элементов

## Известные проблемы

В приложении есть баг, который не позволяет оформить заказ в Chrome. Это нормальное поведение для учебного сервиса, и тесты могут падать при его воспроизведении.
